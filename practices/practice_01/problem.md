# Проблема и метрики

## Проблема

- Пользователь: инженер-ревьюер PR или CI, запрашивающий подсказку по diff
- Ситуация: нужно быстро увидеть ключевые риски в изменениях кода и запустить релевантные проверки
- Что происходит сейчас: сервис отправляет сырой diff во внешний LLM без маскирования и ограничений, вызов без таймаута, а ответ не стандартизирован — ревьюеру сложно доверять и воспроизводить результат
- Почему это мешает пользователю или бизнесу: повышенный риск утечки секретов, нестабильные ответы, потеря времени на ручную проверку и невозможность автоматизировать последующие шаги
- Что не входит в задачу: автоматический approve/merge, автопочинка кода, аутентификация пользователей (допущение)

## Метрики

Выберите измеримые показатели, относящиеся к проблеме. Не используйте VTG, IRR, WACC, CSAT или другую метрику только ради названия.

| Метрика | Текущее значение или способ замера | Целевое изменение | Когда измеряем | Источник данных |
|---|---:|---:|---|---|
| Маскирование секретов в prompt (SEC-1) | Доля запросов к LLM, где известные паттерны секретов отсутствуют в отправленном prompt (через мок-LLM) | 0% → 100% | На каждом релизе и при изменениях редактирования | Журнал мок-LLM / тестовый хук |
| Отклонение больших diff (API-1) | Доля запросов с diff > 20000 символов, получивших 413 | 0% → 100% | Интеграционные и e2e проверки | HTTP-логи API |
| Контролируемый таймаут LLM (REL-1) | Доля запросов с задержкой LLM >10с, завершившихся контролируемым ответом ≤10с | 0% → 100% | Интеграционные тесты с задержкой | Метрики времени ответа и статус-коды |
| Структура ответа (OUT-1) | Доля ответов, соответствующих schema: summary + risks[≤3 с file/line/evidence] + checks | <50% → 100% | Юнит/интеграционные тесты | Снапшоты ответов |

## Почему изменение метрики подтвердит решение проблемы

Повышение доли маскирования секретов исключает утечки и снимает блокер безопасности. Отклонение больших diff защищает SLA и ресурсы. Контролируемый таймаут гарантирует предсказуемость и отсутствие зависаний. Стандартизированная структура ответа делает рекомендации воспроизводимыми и пригодными для автоматизации.
