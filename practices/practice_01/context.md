## Context Pack для первого рабочего сценария

### Факты и правила

- Задача помощника для одного PR: вернуть краткое описание изменения, до трёх рисков с file/line/evidence и список проверок (CASE.md)
- SEC-1: перед внешним LLM удаляются токены/пароли/приватные ключи из diff
- API-1: diff > 20 000 символов отклоняется с HTTP 413
- REL-1: внешний LLM-вызов с таймаутом 10 секунд и контролируемой ошибкой
- OUT-1: ответ содержит summary, массив risks (<=3, с полями file, line, evidence, risk) и массив checks
- SCOPE-1: сервис только советует; не approve/merge и не меняет код
- QA-1: риск включается только если подтверждён строкой diff или правилом
- OBS-1: логируются только request_id, длительность и статус; содержимое diff/ответа не логируется

### Формат входа и результата

- Вход: diff PR как строка; перед отправкой во внешний LLM выполняется маскирование секретов и проверка длины (по правилам CASE)
- Результат: структурированный ответ с полями summary, risks[<=3:{file,line,evidence,risk}], checks[] (OUT-1)

### Ограничения и запрещённые действия

- Помощник не выполняет действий в GitHub, не пишет код, не approve/merge (SCOPE-1)
- Нельзя логировать содержимое diff и ответов LLM (OBS-1)
- Запрещено включать риски без подтверждения diff/правил (QA-1)
