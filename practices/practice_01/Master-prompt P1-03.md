Роль: Ты - инженер, который дозаполняет учебные документы по одному кейсу

Цель: Заполнить одиннадцать файлов практики целиком, не сломав то, что уже написано

Входы: Каталог practices/practice_01 целиком - CASE.md, TRAINING_PR.diff, README.md,
prompts.md и файлы с ответами модели

Источники: только этот каталог, внешние источники не используются

Заполняешь ровно эти файлы:
context.md, problem.md, analysis.md, product_management.md, project_management.md,
adr.md, tests_unit.md, tests_integration.md, tests_load.md, tests_e2e.md, prompts.md

Context Pack:
- Кейс один на все файлы - AI-помощник ревью пул реквестов из CASE.md
- Пустых мест остаться не должно: ни пустых ячеек, ни пунктов после двоеточия,
  ни разделов без текста
- Если шаблон предлагает два взаимоисключающих варианта, выбираешь один и
  заполняешь только его, второй убираешь
- Нет данных в каталоге - пиши разумное допущение и помечай его словом "допущение",
  пропускать место нельзя
- Уже написанный текст не трогаешь: ни ячейки, ни формулировки, ни структуру файла
- Файлы описывают один кейс и не должны противоречить друг другу: метрики из
  problem.md проверяются в тестах, решение в adr.md следует из analysis.md
- В каждом файле блок "Как использовали AI" ссылается на строку prompts.md - значит
  туда надо добавить строку про свою работу
- CASE.md, TRAINING_PR.diff, README.md и файлы с ответами модели только читаются
- Тесты пишутся как проверки, а не как код: вход, ожидаемый результат, чем подтверждаем
- За пределы practices/practice_01 не выходишь, git-команды не запускаешь

Про prompts.md отдельно:
- Строку P1-01 и таблицу Peer review не трогаешь совсем
- Строку P1-02 заполняешь по файлу Answer to master-prompt.md: что модель выдала,
  что в этом полезно, где она ошиблась или вышла за границы. Ошибки ищешь сверкой
  с TRAINING_PR.diff и правилами CASE.md, а не по общим соображениям
- Таблицу "Сравнение двух запусков" заполняешь сверкой двух файлов с ответами.
  Если второй запуск где-то не лучше первого - так и пишешь

Задача:
1. Прочитать CASE.md и TRAINING_PR.diff, понять кейс и правила репозитория
2. Прочитать prompts.md и оба файла с ответами модели
3. Заполнить одиннадцать файлов из списка
4. Дописать в prompts.md строку про свою работу
5. Выписать допущения

Выход:
Только список допущений: файл, место, что предположил
Без вводных фраз, без пересказа задания, без описания кейса,
без отчёта по тому, что ты изменил

Разрешено:
1. Читать любые файлы каталога practices/practice_01
2. Заполнять пустые места в одиннадцати перечисленных файлах
3. Делать допущения, помечая их
4. Добавить строку в таблицу prompts.md

Запрещено:
1. Менять и удалять уже написанный текст
2. Трогать строку P1-01 и таблицу Peer review
3. Менять структуру файлов и колонки таблиц

Шаги:

Условие остановки: если файл нечитаем или его нет - сказать об этом и не
предполагать содержимое. Если непонятно, что вписать - вписать допущение,
а не оставлять пусто

Проверка: перед тем как закрыть файл, пройти по нему сверху вниз и убедиться,
что пустых мест не осталось, а каждое допущение помечено

Условия окончания: все одиннадцать файлов заполнены, они не противоречат друг другу,
все допущения выписаны списком
