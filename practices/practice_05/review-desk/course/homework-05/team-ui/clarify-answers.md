# Clarify: команда UI

## Вопрос 1

### Вопрос (дословно, как показан Ивану)
**Question:** Можно ли ментору добавлять комментарии к строкам сдачи, у которой уже есть ревью, и показывать ли на такой сдаче действие «Комментировать»? (FR-003)

**Why it matters:** От ответа зависит, какие кнопки видит ментор на проверенной сдаче и что получает прямой запрос. Критерии приёмки и тесты для экранов пишутся по этому ответу.

**Recommended:** Option A - комментарий не меняет статус сдачи, а замечание к проверенному коду может понадобиться (например, вдогонку к вердикту). Тогда поведение проверенной сдачи не расходится с pending.

| Option | Description |
|--------|-------------|
| A | Можно всегда: «Комментировать» и форма видны и на сдаче с ревью, и на сдаче без ревью |
| B | Только до ревью: на проверенной сдаче действия «Комментировать» скрыты, прямой запрос получает отказ |
| Short | Provide a different short answer (<=5 words) |

You can reply with the option letter (e.g., "A"), accept the recommendation by saying "yes" or "recommended", or provide your own short answer.

### Ответ Ивана (дословно)
yes

| Option | Description |

| A | Сразу после создания: ученик видит комментарии, пока сдача ещё без ревью |
| B | Только после ревью: до отправки ревью ученик комментариев не видит |
| Short | Provide a different short answer (<=5 words) |

You can reply with the option letter (e.g., "A"), accept the recommendation by saying "yes" or "recommended", or provide your own short answer.

## Вопрос 3

**Question:** Какой ответ должен получить ментор, если отправил комментарий к строке, которой нет в коде (например, номер 99 при 10 строках): страницу сдачи с общим сообщением об ошибке и статусом `400` или страницу «Не найдено» (`404`)? (FR-013)

**Why it matters:** От ответа зависят код ответа и текст на экране, и по нему пишется тест. Формулировка «общее понятное сообщение» без статуса допускает оба варианта.

**Recommended:** Option A - как у остальных форм приложения: ошибка ввода даёт `400` и ту же страницу с сообщением (FR-012). Сдача существует, `404` здесь бы вводил в заблуждение.

| Option | Description |
|--------|-------------|
| A | Страница сдачи с общим сообщением об ошибке, статус `400`; введённый текст не теряется |
| B | Страница «Не найдено», статус `404` |
| Short | Provide a different short answer (<=5 words) |
