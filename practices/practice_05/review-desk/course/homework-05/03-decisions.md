# 03. Решения Ивана по расхождениям спек

Дата: 2026-10-30. Источник: `03-contract-diff.md`, фаза 3. Обоснования, варианты и цена
альтернатив - там, у решения с тем же номером. Здесь только выбор.

Иван принял все 12 рекомендаций как есть: 1-11 по рекомендации, 12 - подтверждение трёх тем,
совпавших по рекомендации агента.

| № | Тема | Решение |
|---|---|---|
| 1 | Строка кода | Одна функция `split_code_lines(code)` в `app/services/line_comments.py`: `\r\n` и `\r` → `\n`, `split("\n")`, финальный пустой элемент отбрасывается, пустой код → `[]`; `line_count = len(split_code_lines(code))`. Шаблон получает `code_lines` и сам не делит. `splitlines()` не использовать |
| 2 | Модель и вид | Вариант логики: `LineCommentView`, поле `line`, `author: str`, порядок `line, created_at, id` |
| 3 | Интерфейс сервиса и контекст | Имена логики (`create_line_comment`, `list_line_comments`, `line_count`, `split_code_lines`) + `can_comment` из UI. Ключи контекста: `line_comments`, `code_lines`, `line_count`, `can_comment`, `line_comment_errors`, `line_comment_form`, `line_comment_max`. `render_submission` загружает комментарии сам, новые аргументы только keyword-only в конце. `app/web/line_comments.py` и `render_submission` - логика; шаблоны и CSS - UI |
| 4 | Выбор строки | Одна форма «номер + текст» под кодом, `id="L{n}"` у строк, комментарии под своей строкой. Без `?line=N`, без ссылки «Комментировать» у строки |
| 5 | Маршрут и редирект | `POST /submissions/{submission_id}/line-comments`; JSON-GET не делать; `303` на `/submissions/{id}[?assignment_id=K]#L{n}` |
| 6 | Разбор номера | `line: str = Form("")`; `re.fullmatch(r"[1-9][0-9]*", s, re.ASCII)`, `len(s) ≤ 19`, `1 ≤ n ≤ line_count`; ошибка - `ValidationError` (400). Тест-таблица из `03-contract-diff.md` |
| 7 | Лимит текста | 2 000 символов, `LINE_COMMENT_MAX = 2_000`, метка «Комментарий к строке», `maxlength` из `line_comment_max` |
| 8 | Ошибки | Ошибки у полей через `_field_error.html`, оба поля проверяются вместе, ввод сохраняется всегда, 400. Для 404 проверяются статус и заголовок «Не найдено», текст `message` не проверяется |
| 9 | Фильтр очереди | `assignment_id` сохраняется: скрытое поле, `queue_filter_or_none`, редирект и 400-перерисовка |
| 10 | Новая попытка | Комментарии остаются на своей `Submission`; в UI сценарий и тест |
| 11 | Мелкие пробелы | (а) ментор видит комментарии всех менторов с именами - явно в UI и тест; (б) до контракта docstring тестов с префиксом `[UI FR-nnn]` / `[Л FR-nnn]` (после контракта - ссылки на требования контракта, см. ниже) |
| 12 | Подтвердить | Принять без изменений: комментировать при любом статусе (С1); ученик видит сразу, в том числе в `pending` (С2); неверный номер строки - 400, не 404 (О1) |
