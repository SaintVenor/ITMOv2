# Демо: построчные комментарии ментора (2-3 минуты)

Сценарий воспроизводим с нуля: отдельная база `demo.db`, она в `.gitignore` (`*.db`).

## Подготовка (до защиты, ~1 минута)

```bash
cd ~/ITMOv2/practices/practice_05/review-desk
export SECRET_KEY=demo-secret DATABASE_URL=sqlite:///./demo.db
rm -f demo.db
for u in "mentor mentor Ментор" "alice student Алиса" "bob student Боб"; do
  set -- $u
  .venv/bin/python -m app.cli create-user --username $1 --role $2 --display-name $3   # пароль спросит дважды
done
.venv/bin/uvicorn app.main:app --port 8000
```

Три браузерных профиля (или обычное окно и два приватных), чтобы не перелогиниваться:
`mentor`, `alice`, `bob`. Адрес: http://127.0.0.1:8000/login.

## Сценарий

| # | Кто | Действие | Что видно |
|---|---|---|---|
| 1 | mentor | «Задачи» → «Новая задача»: название `FizzBuzz`, описание `Выведите числа 1..15` → создать | задача в списке |
| 2 | alice | открыть `FizzBuzz`, вставить код (5 строк, ниже) → сдать | попытка 1, `pending` |
| 3 | mentor | «Очередь ревью» → открыть сдачу Алисы | код с номерами строк 1-5, «Комментариев к строкам пока нет», форма «Комментарий к строке» |
| 4 | mentor | номер `3`, текст `<b>i++</b> лучше вынести` → «Отправить» | редирект на `…#L3`, комментарий под строкой 3, строка выделена, теги показаны как текст |
| 5 | alice | открыть свою сдачу | тот же комментарий под строкой 3, автор «Ментор», формы нет |
| 6 | mentor | номер `6` (N+1), текст `граница` → «Отправить» | `400`: та же страница, у поля «Номер строки: целое от 1 до 5», текст `граница` сохранён, нового комментария нет |
| 7 | bob | открыть адрес сдачи Алисы (`/submissions/1`) | «Не найдено» (`404`): чужая сдача неотличима от несуществующей |

Код для шага 2:

```cpp
#include <cstdio>
int main() {
    for (int i = 1; i <= 15; i++) printf("%d\n", i);
    return 0;
}
```

Если на шаге 6 останется время, можно ещё ввести номер `9223372036854775808` (больше int64):
тоже `400`, не `500`.
