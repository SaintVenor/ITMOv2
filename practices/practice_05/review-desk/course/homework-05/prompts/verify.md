## Блок 3. Собственные прогоны через `fastapi.testclient`

Только `python - <<'PY' ... PY` из каталога проекта, переменные `DATABASE_URL=sqlite://` и
`SECRET_KEY=x`, без записи файлов. Важно: `sqlite://` без `StaticPool` даёт каждому соединению
пустую базу, поэтому повтори схему `tests/conftest.py`: движок с `StaticPool`, `init_db(engine)`,
`app.dependency_overrides[get_db]`, пользователи через `app.services.auth.create_user`, вход
`POST /login`. Вывод каждого прогона - в отчёт.

Сквозной сценарий и границы (ожидание → факт):
1. Ментор: `POST /submissions/{id}/line-comments` `line=2`, `text=<b>x</b>` → `303`,
   `Location` = `/submissions/{id}#L2`; ученик-автор `GET /submissions/{id}` → `200`, текст под
   `id="L2"`, экранирован (`&lt;b&gt;`).
2. `line` = `N+1`, `0`, `05`, ` 5`, `+5`, `٣`, `²`, `1_000`, `9223372036854775808`, `"9"*5000`, пусто →
   `400`, строка в `line_comments` не создана, введённый `text` есть в ответе.
3. Текст: 2 000 символов → `303`; 2 001 → `400`; пробелы → `400`.
4. Права: ученик POST → `403`; другой ученик `GET` чужой сдачи → `404`; без входа → `303` на `/login`.
5. Пути (POST ментором, с полным телом формы `line=1`, `text=x`, иначе 404/400 будет ложным):
   `/submissions/abc/line-comments` и `/submissions/99999999999999999999/line-comments` → `404`, не `500`.
6. Фильтр очереди: `assignment_id=<id задачи>` → `Location` с `?assignment_id=…#L2`; `abc`,
   `//evil.example`, `99999999999999999999` → `Location` без query.
7. Код с `\r\n` и одиночным `\r`: номера строк на странице совпадают с номерами, которые принимает POST.
8. Ревью с ошибкой (`POST /submissions/{id}/review` без вердикта) на сдаче с комментарием →
   `400`, комментарий виден.
9. Новая попытка: комментарии остаются на старой сдаче, у новой - пустое состояние.
10. `GET /submissions/{id}/line-comments` → не `200`.
11. Совместимость с существующей базой: в памяти создай все таблицы, кроме `line_comments`
    (через `Base.metadata.create_all(engine, tables=[...])`), добавь пользователя и сдачу, затем
    `init_db(engine)`: таблица появилась, старые данные читаются, страница сдачи открывается.
