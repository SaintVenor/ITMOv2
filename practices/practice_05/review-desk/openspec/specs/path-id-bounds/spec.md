# Path Id Bounds Specification

## Purpose

Эта capability описывает, как система отвечает на запросы с числовым id в пути (`assignment_id`, `submission_id`), который не укладывается в диапазон `INTEGER` SQLite: такой id SHALL считаться несуществующим ресурсом.

## Requirements

### Requirement: Переполняющий id задачи при просмотре задачи
`GET /assignments/{assignment_id}` SHALL отвечать `404` «Не найдено», если `assignment_id` не представим в SQLite `INTEGER` (вне диапазона `-2^63 … 2^63-1`), без обращения к базе данных.

#### Scenario: Id ровно на верхней границе представимого диапазона
- **WHEN** пользователь открывает `GET /assignments/9223372036854775807` (2^63-1) и задачи с таким id нет
- **THEN** система отвечает `404` «Не найдено» — так же, как для любого другого отсутствующего id

#### Scenario: Id на единицу больше верхней границы
- **WHEN** пользователь открывает `GET /assignments/9223372036854775808` (2^63)
- **THEN** система отвечает `404` «Не найдено», а не `500`

#### Scenario: Сверхбольшой id
- **WHEN** пользователь открывает `GET /assignments/99999999999999999999`
- **THEN** система отвечает `404` «Не найдено»

#### Scenario: Сверхмалый (отрицательный) id
- **WHEN** пользователь открывает `GET /assignments/-99999999999999999999`
- **THEN** система отвечает `404` «Не найдено»
