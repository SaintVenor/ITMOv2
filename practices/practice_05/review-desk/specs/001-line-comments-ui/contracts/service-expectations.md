# Что UI ожидает от команды логики

Интерфейс модуля `app/services/line_comments.py`, маршрута и контекста задан общим контрактом
[`specs/line-comments-contract.md`](../../line-comments-contract.md); этот файл только перечисляет, на что опирается UI.

## Функции и данные

| Ожидание UI | Пункт контракта |
|---|---|
| `list_line_comments(db, user, submission_id) -> list[LineCommentView]` в порядке `line`, `created_at`, `id`; `author` - строка | LC-02, LC-03, LC-07 |
| `can_comment(user, submission) -> bool`: `True` для любого `mentor` в любом статусе, `False` для ученика | LC-07, LC-23 |
| `split_code_lines(code)` и `line_count(submission)` - единственный источник строк и их числа | LC-04, LC-05 |
| `create_line_comment(db, user, submission_id, line: str, text)` сама разбирает `line` | LC-07, LC-15 |
| Лимит текста `LINE_COMMENT_MAX = 2_000`, в шаблон приходит как `line_comment_max` | LC-06 |
| Ключи контекста страницы сдачи заполняет `render_submission` на всех путях рендера | LC-11, LC-12 |

## Исключения и их показ

| Исключение | Как UI показывает | Пункт |
|---|---|---|
| `Forbidden` | `403`, стандартная страница ошибки | LC-14 |
| `NotFound` | `404` «Не найдено»; текст сообщения UI не проверяет | LC-14, LC-17 |
| `ValidationError({"line": …, "text": …})` | `400`, страница сдачи, ошибки у своих полей, ввод сохранён | LC-14, LC-16 |

Формат номера строки - каноничное ASCII-целое в `1..line_count` (LC-15); сообщения на русском, готовые к показу.

## Чего UI не делает и не требует

- Не хранит и не фильтрует комментарии по статусу сдачи: ученик-автор получает все комментарии сразу (FR-017, LC-24).
- Не проверяет права и диапазон строк самостоятельно (только показывает `can_comment`).
- Не делит код на строки и не считает их число.
- Не создаёт `app/web/line_comments.py` и не правит `render_submission` (LC-26).
- Не ожидает правок существующих таблиц; чужая сдача для ученика остаётся `NotFound` из `get_submission_for`.

## Зависимость порядка работ

Сначала логика (LC-28): роут, `render_submission` и сервис. Шаблоны UI пишутся на настоящем сервисе; тесты UI его
используют.
