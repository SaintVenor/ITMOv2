# Data Model (вид данных для UI): построчные комментарии

Таблицу, ограничения и миграцию `create_all` определяет команда логики (LC-01; бриф: только новая таблица,
существующие не меняются). Здесь - то, что UI читает и передаёт; поля соответствуют Key Entities спеки и
общему контракту [`specs/line-comments-contract.md`](../line-comments-contract.md).

## LineCommentView (читает UI, LC-02)

| Поле | Тип | Использование в UI |
|---|---|---|
| `id` | int | id элемента `comment-<id>` для якорей/тестов |
| `line` | int (≥ 1) | группировка под строкой |
| `text` | str | вывод с автоэкранированием, `white-space: pre-wrap` |
| `author` | str (`display_name`) | «Автор · дата» |
| `created_at` | datetime | фильтр `dt` (UTC) |

Порядок: `line`, `created_at`, `id` (LC-03) - обеспечивает сервис. Группировку по строке делает шаблон.

## Данные страницы сдачи (контекст шаблона, LC-11)

| Ключ | Назначение |
|---|---|
| `submission` | существующий `get_submission_for`, как сейчас |
| `line_comments` | `list[LineCommentView]` из сервиса; вывод под строками, пустое состояние (FR-011) |
| `code_lines` | `list[str]`: строки кода для вывода с номерами `1..` (LC-04); шаблон код сам не делит |
| `line_count` | `int`, число строк кода (LC-05) |
| `can_comment` | `bool`: показ формы комментария (FR-002, FR-008) |
| `line_comment_errors` | `dict[str, str]`: ошибки полей `line` и `text` (FR-012, FR-013) |
| `line_comment_form` | `dict[str, str]`: введённые `line` и `text` при `400` |
| `line_comment_max` | `int`: значение `maxlength` поля текста (LC-06) |

Ключ `errors` - ошибки ревью, для комментариев не используется. Контекст заполняет `render_submission` на всех
путях рендера (LC-12).

## Связи и жизненный цикл

- Сдача 1 - N комментариев. Комментарий создаётся только ментором и далее не меняется (редактирования и удаления нет).
- Комментарии привязаны к своей `Submission` и не переносятся на новую попытку (LC-22, FR-019).
- Статус сдачи и ревью комментарий не затрагивает (FR-003, LC-23); видимость ученику не зависит от статуса (FR-017, LC-24).
- Нумерация строк - только `code_lines` (LC-04); UI число строк не считает.
