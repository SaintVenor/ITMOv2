## Пробелы
1. [GET /files, service.py:78-80; sandbox.py:21-25] Нет угрозы на основное поведение: анонимное чтение любых файлов Sandbox. Через user=.. и path можно читать files/<чужой>/… и private/operator-note.txt (например, user=.., path=private/operator-note.txt). → Добавить отдельную угрозу (STRIDE: I/E), с серьёзностью не ниже Высокой (утечка A4, A5), предусловие «нет», последствие «чтение чужих чеков и служебной заметки»; меры: требовать токен, разрешать только свой чек (owner из сессии), запрещать выход из подкаталога files/<owner>, валидация user/path; тест на попытки чтения чужих/privаte файлов.
2. [Разд. 4, T11, service.py:62-73] В мерах для T11 нет описания решения (пустая «Мера защиты») → Добавить явную меру: игнорировать цену из тела, всегда брать из каталога; валидировать тип и знак; аудит исходной цены.
3. [T13 /admin/export, service.py:74-77] Неверно занижена серьёзность. Без аутентификации и по одному заголовку «X-Role: staff» выдаются ПДн всех пользователей, что соответствует критерию «Критическая» из разд. 3 (анонимная компрометация ПДн). → Повысить серьёзность до Критической; при необходимости скорректировать сводку 3.3.
