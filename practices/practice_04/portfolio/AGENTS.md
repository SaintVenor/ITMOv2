# Правила проекта для агента

Сайт-портфолио: FastAPI-приложение, главная страница и JSON API проектов.

## Источники
- Требования и контракт API: `docs/requirements.md`. Реализуй только то, что там описано.
- Данные о проектах: `data/projects.json`. Факты о проекте (название, стек, описание) бери через MCP tool `portfolio_get_project`, а не придумывай.
- Пример теста: `tests/test_projects.py`. Новые тесты пиши в том же стиле, через `TestClient`.

## Проверка
- Единственная команда проверки: `sh scripts/check.sh`. Задача не готова, пока она не выводит `CHECK: PASS`.
- После каждой правки файла hook сам запускает `scripts/check.sh` и дописывает результат к ответу инструмента. Читай этот вывод.

## Процесс
- Новую функциональность делай по skill `test-driven-development`: сначала тест, показать его падение, затем минимальная реализация.
- По документации FastAPI и Pydantic сверяйся через Context7 (`use context7`), а не по памяти.

## Нельзя без явного поручения
- Менять `scripts/check.sh`, `.opencode/`, `opencode.json` и `data/projects.json`.
- Удалять или ослаблять существующие тесты ради зелёного результата.
- Добавлять зависимости, не указанные в `requirements.txt`.
- Делать `git commit` и `git push`.
