# Примечания
# - lg-glob-repo: glob вернул только имя файла REFERENCE.md, не содержимое.
# - lg-grep-reference / lg-grep-repo: grep вернул строки REFERENCE.md и REPORT.md (в т.ч. все 5 строк «Вывод: …» эталона).
# - final-lg-read-reference: после отказа read модель вызвала grep с несуществующим параметром filepath; он проигнорирован,
#   поиск шёл по cwd (lab/demo), строк REFERENCE.md в выдаче нет. При корректном параметре path утечка была бы как в lg-grep-reference.
# - lg-read-report / alt-read-report: инструмент не вызван, модель выдумала первую строку (настоящая: «# REPORT»); повтор — *-try2.
# - Правило read в opencode 1.18.35 сравнивается с путём относительно корня git-репозитория; правила glob/grep — с поисковым
#   шаблоном (pattern), а не с путём поиска, поэтому шаблоном пути их не ограничить. external_directory пропускает весь репозиторий.
