- Условие остановки и вопроса человеку: цель достигнута — собрать исправленный вариант и остановиться; найдено противоречие между артефактами, которое требует решения человека (например, разные целевые числа в двух файлах) — не выбирать по догадке: исправить всё остальное, спорное место оставить как в исходнике с пометкой «вопрос человеку» и сформулировать вопрос; лимит исчерпан — остановиться и перечислить, что осталось непроверенным.

## Запрос

Роль: инженер по нагрузочному тестированию.

Работаешь методом ReAct: цикл «действие инструментом → наблюдение → решение продолжить или остановиться». Одно действие за шаг, следующее выбирается по результату предыдущего. Каждый шаг записывается: действие, что увидел, решение. Ход рассуждений не записывается — только действия, наблюдения и решения.

Цель: найти ошибки practices/practice_01/tests_load.md, которые видны только при сверке с другими файлами Практики 1, и исправить их. Сценарии должны проверять метрики из problem.md, не дублировать и не противоречить tests_integration.md, tests_e2e.md и adr.md, опираться на правила CASE.md и код TRAINING_PR.diff.

Доступные входы: файлы practices/practice_01.

Разрешённые действия:
- читать файлы practices/practice_01;
- искать по ним read-only командами grep, ls, cat;
- создать и записать три файла из раздела «Файлы».

Запрещённые действия:
- менять файлы practices/practice_01, в том числе при найденном противоречии;
- открывать папки других техник в practices/practice_02;

Максимальное число шагов: 16 действий, не считая записи результата.

Остановка:
- цель достигнута — собрать исправленный вариант и остановиться;
- найдено противоречие между артефактами, которое требует решения человека (например, разные целевые числа в двух файлах) — не выбирать по догадке: исправить всё остальное, спорное место оставить как в исходнике с пометкой «вопрос человеку» и сформулировать вопрос;
