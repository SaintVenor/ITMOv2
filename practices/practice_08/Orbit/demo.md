# Орбита · Практика 8

**Основной сценарий.** Студент находит свободную субботу и назначает на неё шаг «Собрать черновик». После перезагрузки шаг остаётся в календаре. Когда студент отмечает его выполненным, прогресс плана «Снять первый короткий ролик» меняется с **1 из 3** на **2 из 3**. [Свободный день](evidence/scenario/free-day.png) → [Выбор шага](evidence/scenario/choose-step.png) → [Назначение после перезагрузки](evidence/scenario/assigned-after-reload.png) → [Результат в плане](evidence/comparison/plan-app-desktop.png)
